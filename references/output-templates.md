# Output Templates

Use these as compact defaults. Put code high in the response and keep the preamble short.

## New indicator

1. One short paragraph on what the script does.
2. Full Pine v6 code block.
3. `Settings and alerts:` short note.
4. `Limitations:` short note.

## New strategy

1. One short paragraph on what the strategy does.
2. Full Pine v6 code block.
3. `Usage:` short note.
4. `Backtest assumptions:` short note.
5. `Limitations:` short note.

## Review or fix

1. `Root cause:` one short paragraph.
2. Full corrected Pine v6 code block.
3. `What changed:` short note.
4. `Caveats:` short note.

## Publication draft

Use this order when the user wants publish-ready copy:

1. Overview
2. How it works
3. Input groups
4. Alerts and automation
5. Markets and timeframes
6. Limitations
7. Disclaimer

## If the brief is incomplete

State assumptions briefly before the code, for example:
- I assumed confirmed-bar entries.
- I assumed one position at a time.
- I assumed higher-timeframe data should use confirmed mode.
